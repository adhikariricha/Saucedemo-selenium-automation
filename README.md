# SauceDemo Selenium Automation

## Overview

This project automates the complete purchase workflow of the SauceDemo website using Selenium WebDriver with Python. It demonstrates end-to-end web UI automation, including user login, product selection, cart verification, checkout, and order confirmation.

## Website

https://www.saucedemo.com/

## Features

- Login with valid credentials
- Add product to cart
- View shopping cart
- Verify selected product
- Complete checkout process
- Place order successfully
- Verify order confirmation
- Return to the products page

## Technologies Used

- Python
- Selenium WebDriver
- Microsoft Edge WebDriver
- Git
- GitHub

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/saucedemo-selenium-automation.git
```

### 2. Navigate to the project folder

```bash
cd saucedemo-selenium-automation
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the automation script

```bash
python order_placement.py
```

## Test Scenario

1. Open the SauceDemo website.
2. Log in using valid credentials.
3. Add a product to the shopping cart.
4. Open the cart and verify the selected product.
5. Proceed to checkout.
6. Enter customer details.
7. Complete the order.
8. Verify the successful order confirmation.
9. Return to the products page.
